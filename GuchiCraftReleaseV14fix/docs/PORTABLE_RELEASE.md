# Portable Release

The portable build is the diagnostic and distribution step before returning to `jpackage`.
It packages the launcher with:

- a compact Java 21 runtime generated by `jlink`;
- Windows JavaFX modules in `javafx/`;
- launcher and runtime dependencies in `app/`;
- the external updater JAR in `updater/`;
- a normal launcher BAT and a diagnostic BAT.

## Build

Run from the project root:

```text
build-portable.bat
```

The script asks for a semantic version such as `1.0.0` and writes the result to:

```text
release/portable-output/GuchicraftLauncher-1.0.0-portable/
release/portable-output/GuchicraftLauncher-1.0.0-portable.zip
```

## Test

Extract the ZIP to a new folder and run:

```text
GuchicraftLauncher.bat
```

If the window does not open, run:

```text
GuchicraftLauncher-debug.bat
```

The diagnostic window stays open and prints the exact Java or JavaFX error.
