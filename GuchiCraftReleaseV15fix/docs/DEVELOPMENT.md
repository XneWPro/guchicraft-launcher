# Схема разработки

1. Клиентские файлы хранятся в отдельном репозитории `guchicraft-launcher-files`.
2. Builder формирует и публикует `launcher/manifest.json`.
3. Launcher читает manifest и приводит локальный клиент к указанному состоянию.
4. Общие модели и хеширование изменяются только в модуле `common`.

## Что менять владельцу сервера

Обычное обновление сборки выполняется только через Builder: версия Minecraft, Fabric, Java, память, адрес сервера и файлы модпака. Исходники Launcher при этом менять не нужно.
