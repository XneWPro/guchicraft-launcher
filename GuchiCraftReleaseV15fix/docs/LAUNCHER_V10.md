# Launcher v10 — SRV и неблокирующий статус

- Адрес из `manifest.json` передаётся Minecraft без принудительного `:порт`.
- Для информационного статуса лаунчер разрешает DNS SRV `_minecraft._tcp`.
- Если статус получить не удалось, это не блокирует кнопку «Играть».
- При отсутствии SRV для проверки используется стандартный порт 25565.
- Явный адрес вида `host:port` продолжает поддерживаться.
